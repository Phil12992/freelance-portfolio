# 🐳 Gehärteter Docker & Nginx Homelab Stack

Produktions-Setup für sichere Linux- und Homelab-Umgebungen.

## Sicherheits-Highlights
- **Security Headers:** HSTS, X-Frame-Options, X-Content-Type-Options, Strict Content-Security-Policy.
- **Rate-Limiting:** Schutz vor Brute-Force und DDoS mittels Nginx Memory Zone.
- **Least Privilege:** Non-root User & `no-new-privileges` in Docker Compose.
