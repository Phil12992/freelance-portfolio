# 🤖 Projekt: Automatisierungs-Bots & Data Scraper

Lösungen zur automatisierten Überwachung von Datenquellen und direkten Alarmierung.

## Anwendungsbeispiele
1. **Telegram Benachrichtigungs-Bot:** Sendet Statusberichte, Fehler-Alerts oder Messwerte in Echtzeit an private Chats oder Kanäle.
2. **Web-Scraper & Monitor:** Überwacht Webseiten auf Änderungen (z.B. neue Angebote, Verfügbarkeiten) und verarbeitet die Daten strukturiert in JSON/CSV.
3. **Scheduled Runner:** Automatische periodische Ausführung von System- und Wartungsaufgaben.

## Tech-Stack
- Python 3.11+
- AsyncIO / aiohttp / httpx
- Beautiful Soup 4 / Playwright
- Docker Deployment
